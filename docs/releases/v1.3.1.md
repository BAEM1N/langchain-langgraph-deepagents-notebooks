# v1.3.1 — Offline Execution Verification

전체 241개 노트북을 외부 API 제외 조건으로 실행 검증한 패치 릴리즈다.

- 모든 코드 셀 실행 완료: 46개. 외부·의존·환경 조건 제외 후 로컬 검증 완료: 195개.
- 코드 셀 892개 실행 성공, 1090개 명시적 제외. 실행 오류와 비밀값 검사 적중은 0건.
- 캐싱 미들웨어 import, 에이전트·서브에이전트 인자, 실행 메타데이터, tracing-off 처리, LiteLLM import, async loader를 수정했다.
- 대응 Typst·데크 소스와 교재 2종·데크 3종을 갱신했다. 전체 데크 1,206장 유지.
- 오프라인 실행기와 10개 회귀·보안 검사 추가. 전체 테스트 26개 통과.

외부 서비스는 실제 호출하지 않았다. 선택 패키지·로컬 모델·서버 조건이 없는 셀도 명시적으로 제외했으며, 모든 노트북의 원격 통합 성공을 주장하지 않는다. 실제 키와 비밀 파일은 배포물에 포함하지 않는다.
