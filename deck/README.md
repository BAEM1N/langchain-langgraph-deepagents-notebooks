# Agent Engineering Course Deck PDFs

이 폴더는 01~05 과정의 PDF 배포 산출물만 포함합니다.

## 포함 파일

각 과정별로 다음 2종을 제공합니다.

- `*.pdf` — 슬라이드 PDF
- `*_대본.pdf` — 강사용 상세 대본 PDF

PPTX 원본은 용량이 커서 Git 일반 커밋에는 포함하지 않습니다. 필요 시 GitHub Release, Git LFS, 또는 Google Drive 배포 링크로 분리합니다.

## 과정 목록

| 번호 | 파일 접두사 | 주제 |
|---:|---|---|
| 01 | `01_beginner` | AI 에이전트 개발 입문 |
| 02 | `02_langchain` | LangChain v1 에이전트 개발 |
| 03 | `03_langgraph` | LangGraph 상태 그래프와 워크플로 |
| 04 | `04_deepagents` | Deep Agents 장기 작업 에이전트 |
| 05 | `05_advanced` | 고급 에이전트 엔지니어링 |

원본 실습 노트북은 repository의 `01_beginner/`~`05_advanced/`를 기준으로 합니다.
