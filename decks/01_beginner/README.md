| 파일 | 용도 |
|---|---|
| `01_beginner.pdf` | 배포/검토용 슬라이드 PDF |

PPTX는 용량이 커서 전 과정 일괄 Git 커밋 대상에서 제외할 수 있습니다. 필요하면 GitHub Release, Git LFS, 또는 Google Drive 링크로 분리합니다.
