# 01_beginner Deck

이 폴더는 `01_beginner/` 노트북 트랙을 바탕으로 만든 강의용 산출물을 보관합니다.

## 포함 파일

| 파일 | 용도 |
|---|---|
| `01_beginner.pptx` | 강의장 발표용 PowerPoint. 현재 형식은 슬라이드별 전체 화면 이미지 + 발표자 노트입니다. |
| `01_beginner.pdf` | 배포/검토용 슬라이드 PDF |
| `01_beginner_대본.md` | 강사용 상세 대본 Markdown |
| `01_beginner_대본.pdf` | 강사용 상세 대본 PDF |

## 편집 방법

PowerPoint에서 텍스트를 직접 편집하는 네이티브 텍스트형 PPTX가 아닙니다. 내용을 바꾸려면 `decks/source/01_beginner/content/`의 Python 원본과 필요 시 CSS/asset을 수정한 뒤 `decks/source/build_all_decks.py`로 재생성합니다.
