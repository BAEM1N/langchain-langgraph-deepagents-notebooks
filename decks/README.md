# Lecture Decks

강의용 deck 산출물을 보관하는 폴더입니다.

- 노트북 원본은 repository의 `01_beginner/`~`08_integration/`에 둡니다.
- 강의 배포/촬영/발표 산출물은 `decks/<module>/` 아래에 둡니다.
- 단수형 `deck/` 폴더는 사용하지 않습니다. 모든 배포 산출물은 `decks/`로 통합합니다.
