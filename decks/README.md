# Lecture Decks

강의용 deck 산출물을 보관하는 폴더입니다.

- 노트북 원본은 `01_beginner/`~`08_integration/`에 둡니다.
- 강의 배포/촬영/발표 산출물은 `decks/<module>/` 아래에 둡니다.
- 예: `decks/01_beginner/01_beginner.pdf`, `decks/01_beginner/01_beginner.pptx`, `decks/01_beginner/01_beginner_대본.md`
